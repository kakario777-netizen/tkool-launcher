# 쯔꾸르 런처

아야네오 같은 휴대용 PC에서 터치·게임패드만으로 쯔꾸르(RPG Maker) 게임을 고르고 실행하는 가벼운 런처.

- 설치 없이 `TkoolLauncher.exe` 하나 (윈도우 10/11 기본 .NET Framework 4.8 사용)
- 설정 저장 위치: `내 문서\쯔꾸르 런처\settings.ini`
- 지원 버전 자동 인식: 2000/2003, XP, VX, VX Ace, MV, MZ

다운로드는 [릴리스 페이지](https://github.com/kakario777-netizen/tkool-launcher/releases)에서.
